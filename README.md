# 玄枢 H3 优化器（ComfyUI_XuanShuH3Optimizer）

MiniMax H3 加速与画质优化节点套件，专为 RTX 5060 8GB 优化。

**末梦秋花系列**：一个等风来（加速），一个逆风飘（保人），一个顺风飘（跳步）。

---

## 快速开始

### 安装

1. 下载本仓库
2. 解压到 `ComfyUI/custom_nodes/` 目录
3. 重启 ComfyUI
4. 搜索"末梦秋花"找到节点

### 最简用法（推荐）

```
加载模型 → 末梦秋花v4t(等风来) → 采样器
```

就一个节点，自动选最快的注意力后端，零画质损失。第一次跑会探针几秒钟，之后自动记住。

---

## 节点详解

### 1. 末梦秋花v4t(等风来) —— 无损加速

**干什么**：拦截注意力计算，现场比武选最快的后端（pytorch / sage / ck_int8）。

**为什么无损**：不跳步、不改 latent、不做近似——每次都全算，只是选最快的算路。

**两个进化（相比旧版 v3t1）**：
- **磁盘缓存**：选过一次就记住，下次启动 ComfyUI 直接用，跳过探针
- **显存感知降级**：长序列跑到后面显存紧张了，自动从 ck_int8 降级到 pytorch，不会 OOM 崩掉

**参数**：

| 参数 | 默认值 | 说明 |
|---|---|---|
| mode | auto_probe | passthrough=不做任何事，auto_probe=自动寻优 |
| quality_mode | speed_priority | speed_priority=纯比速度 / lossless_priority=pytorch优先 |
| vram_aware | true | 显存不够自动降级 |
| vram_margin_mb | 200 | 显存安全余量(MB) |
| report_stats | disable | enable=打印累计统计 |

**接线**：
```
UNET Loader → [末梦秋花v4t] → KSampler
```
输入输出都是 MODEL，串在模型和采样器之间。

---

### 2. 末梦秋花(逆风飘)v5x —— 保人物一致

**干什么**：在 Ref2VA 三参考图工作流中，防止人物被多步采样磨平。

**原理**：不改 latent（v4 教训：改 latent 会伪影），只在 condition 层定期校正参考图特征权重。弹簧式微抵抗——偏了就拉，不偏不动，不记状态每步重测。

**什么时候用**：
- Ref2VA 三参考图（场景+女生+男生）工作流
- 跑出来的人物跟参考图不像
- 多段续写时人物逐渐变脸

**参数**：

| 参数 | 默认值 | 说明 |
|---|---|---|
| total_steps | 6 | 推理总步数（必须跟采样器步数对齐） |
| warmup_steps | 3 | 前 N 步校正力度放大，定型参考图 |
| end_protect_steps | 2 | 最后 N 步降低校正力度，别动成片 |
| conc_high | 0.95 | 浓度高于此值不校正（没偏就不动） |
| conc_low | 0.85 | 浓度低于此值硬拉（明显偏了） |
| max_alpha | 0.3 | 校正力度上限（防止画面卡顿） |
| shape_protection | true | 形状变化自动重置基准 |
| report_stats | false | 打印每步浓度和校正力度 |

**接线**：
```
UNET Loader → v4t(等风来) → [末梦秋花(逆风飘)v5x] → KSampler
```
串在 v4t 后面，采样器前面。total_steps 必须跟采样器步数一致。

---

### 3. 末梦秋花v3s1(顺风飘) —— 跳步加速

**干什么**：20步标准链上，判断哪些步可以跳过不算，直接复用上一步结果。

**什么时候用**：
- 20步标准链（不是4步蒸馏链）
- 追求极限速度，可以接受轻微画质损失

**注意**：4步蒸馏链（LightX2V 4step LoRA）上不要用——4步里只有1步可跳，省的时间不值人脸崩的风险。

**参数**：大部分默认值不用动，只改 `total_steps` 跟采样器对齐。

## 推荐组合

### 组合 A：蒸馏 LoRA 4步跑 Ref2VA（人物一致 + 快）

```
UNET → v4t(等风来) → v5x(逆风飘) → KSampler(4步)
```

- v4t 选最快 kernel
- v5x 保人物跟参考图像
- 不用 v3s1（4步没什么可跳的）

### 组合 B：20步标准链全速跑

```
UNET → v4t(等风来) → v3s1(顺风飘) → KSampler(20步)
```

- v4t 选最快 kernel
- v3s1 跳步缓存，15步可跳
- 两个正交叠加，速度最快

### 组合 C：纯基准（什么都不加）

```
UNET → KSampler
```

就是裸跑，用来做对比基准。

## 常见问题

**Q: v4t 第一次跑为什么等了几秒？**
A: 第一次在探针测试3个后端的速度，选最快的。之后存到磁盘，第二次跑直接用，不等了。

**Q: 控制台一直刷"显存不足降级 pytorch"？**
A: v4t 的显存感知触发了。降级只打印一次，后续不重复。如果一直刷，把 `vram_margin_mb` 从 200 调到 100。

**Q: v5x 跑出来画面变卡了？**
A: `max_alpha` 太大了。默认 0.3，调到 0.15 试试。

**Q: v3s1 在4步 LoRA 上为什么没效果？**
A: 4步里只有1步可跳，省的时间约等于零。v3s1 是给20步标准链用的。

**Q: 跟其他加速节点冲突吗？**
A: 本套件节点互斥——后串的会覆盖先串的。不要同时串两个 v3 系列节点。
