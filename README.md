## v4t 等风来 · 无损加速

拦截 H3 的注意力计算，现场比武选最快后端（pytorch / sage / ck_int8）。

**为什么无损**：不跳步、不改 latent、不做近似——每次都全算，只是选最快的算路。

**两个核心功能**：
- **磁盘缓存**：选过一次就记住，下次启动直接用，跳过探针
- **显存感知降级**：长序列跑到后面显存紧张了，自动降级不崩

**参数**：

| 参数 | 默认 | 说明 |
|---|---|---|
| mode | auto_probe | 自动寻优 |
| quality_mode | speed_priority | 纯比速度 |
| vram_aware | true | 显存不够自动降级 |
| vram_margin_mb | 200 | 显存安全余量(MB) |
| report_stats | disable | 开启打印统计 |

## v5.2s 逆风飘 · 保人物一致

Ref2VA 三参考图工作流专用。跑出来人物跟参考图不像、多段续写变脸？开这个。

**原理**：不改 latent，只在 condition 层定期校正参考图特征权重。偏了就拉，不偏不动。

**参数**：

| 参数 | 默认 | 说明 |
|---|---|---|
| total_steps | 6 | 跟采样器步数对齐 |
| warmup_steps | 3 | 前3步定型参考图 |
| end_protect_steps | 2 | 最后2步别动成片 |
| conc_high | 0.95 | 浓度高于此不校正 |
| conc_low | 0.85 | 浓度低于此硬拉 |
| max_alpha | 0.3 | 校正力度上限 |

## 常见问题

**Q: 第一次跑为什么等几秒？**
A: 在探针测试3个后端速度，选最快的。之后存磁盘，第二次直接用。

**Q: 控制台刷"显存不足降级"？**
A: 显存感知触发了。降级只打印一次。一直刷就把 margin 从 200 调到 100。

**Q: v5.2s 画面变卡？**
A: max_alpha 太大。默认 0.3，调到 0.15。
